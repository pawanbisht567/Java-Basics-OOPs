To Build the Code, below command will generate the .class file

```
    javac <file-name>.java
```

To run the code, this below file should be run without any extension name

```
    java <file-name>
```

Important Notes

```
    1. JVM is inside of JRE, JRE have all the utility libraries to use in our code.
    2. JDK -> JRE -> JVM
```
